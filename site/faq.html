Frequently asked questions

The maintained repository FAQ is authoritative. This page is the short version.

Is this an emulator?

No. GoldenEye Native builds from the n64decomp/007 reconstruction of the game's C source and compiles it as a native application for the host operating system.

Do I need a ROM?

Yes. You provide your own supported US retail cartridge dump locally. The tracked public tree is source-only and is intended not to contain ROMs or extracted game assets.

Which desktop platforms work?

Linux, macOS and Windows have native builds. The complete 1.0 retail campaign was human-certified on the primary Ubuntu 24.04 x86-64 / Intel Iris Xe system. macOS builds on Apple silicon and Intel with OpenGL and Metal. Windows builds natively with mingw-w64 but has not received the same full human campaign certification.

What about Apple TV, iPhone/iPad and Android?

They are bring-up targets, not equivalent to the desktop release status. tvOS builds, signs and deploys to configured hardware. iOS builds and needs a paired device for device deployment. Android has a compiling arm64 GLES port layer and touch controls, but the game has not yet been run there.

Can it render above 60 fps?

Yes. The real-clock free-run path can keep the main game field clock near its intended rate while rendering substantially faster. That is a measured timing improvement, not a claim that every frame-counted gameplay and animation subsystem is completely converted to real time.

Does multiplayer work?

Local split screen supports two, three and four players. Campaign co-op and LAN multiplayer are inherited beta systems from pre-takeover work. Co-op missions still assume one Bond in important ways, and LAN sessions have measured desynchronization. Neither was part of the GoldenMark64 1.0 campaign-certification pass.

Are bots real?

Yes, as a beta feature. The tree has player-input bots and compiled AI archetypes that can be attached to spawned characters. Match setup and higher-level bot integration are still evolving.

Can I use HD texture packs?

Yes. Texture-hash PNG replacement is implemented and has been verified end to end. No game-derived texture pack ships with the project.

Where is the Windows download?

There is not yet an official no-code Windows package on the Releases page. The ROM-free setup app exists as a release candidate and is validated in CI, but publication is a separate future release step. Developers can build Windows from source now.

Who made this?

The original GoldenEye Native port was developed by @SegfaultEvan. After that upstream repository disappeared, this repository became the @GoldenMark64 community continuation. The reconstructed game source is the work of the n64decomp/007 project and its contributors.

Is it legal?

The project does not make a blanket legal claim. Read the current licensing and provenance record, and use your own cartridge dump only in a way permitted where you live.
