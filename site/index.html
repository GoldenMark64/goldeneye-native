One launcher.
Modern controls.

Mission, ruleset, cheats, video, mouse and controller settings are exposed without requiring hand-edited config files.

Display controls.
Without config surgery.

CRT, widescreen and other presentation settings are exposed through the launcher while the source build stays local.

Mods stay
explicit and opt-in.

Optional mod packs can be enabled or disabled from the launcher without making experimental behavior part of the certified base campaign.

Code you can
actually inspect.

Lua mods and native diagnostics sit beside reconstructed game source, which makes behavior measurable and repairable at source level.

This is a native source port, not an emulator. The project compiles reconstructed game source for the host CPU and renders through native desktop graphics APIs. That makes source-level behavior, timing and native ABI bugs directly inspectable.
