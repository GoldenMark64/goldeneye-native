Install or build it

The public repository is source-only. Your own supported cartridge dump is read locally to build the playable program on your machine.

What you need

Game revisionGoldenEye 007, US retail
SHA-1abe01e4aeb033b6c0836819f549c791b26cfde83
Free diskAbout 4 GB
First buildRoughly 10–40 minutes, machine dependent

The project does not supply or upload a ROM. Do not attach a ROM, save, extracted asset or locally built playable executable to an issue or pull request.

macOS and Linux

Clone the current repository and use the resumable installer:

git clone https://github.com/GoldenMark64/goldeneye-native.git
cd goldeneye-native
bash tools/install.sh --rom /path/to/your-rom.z64

On macOS there is also a double-click Install on Mac path. On Linux, the installer prints the package-manager command for any missing dependency and never runs sudo itself.

Windows

There is not yet an official downloadable no-code Windows setup package. The ROM-free setup application exists as a release candidate and is validated in CI, but the workflow does not publish it.

Developers and advanced users can build from source today:

git clone https://github.com/GoldenMark64/goldeneye-native.git
cd goldeneye-native
powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 -Rom C:\path\to\your-rom.z64

For the future no-code package and its current availability, read WINDOWS_INSTALL.md.
